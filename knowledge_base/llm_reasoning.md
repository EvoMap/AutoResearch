# Synthetic Language Model Reasoning Budgets

This synthetic direction exists only to exercise the public Idea Pipeline. It contains no real research corpus or unpublished experimental claims.

## Common Pitfalls

- Longer output does not by itself make reasoning more reliable.
- More samples on the same task cannot replace a generalization check on an independent test set.

## Research Opportunities

- Compare one long reasoning trace, several short traces and verifier-guided selection under the same token budget.
- Report accuracy, compute, failure modes and verifier error rates separately.
