# Synthetic Agent Memory Direction

This synthetic direction exists only to exercise the Idea Pipeline with public, invented content.

## Common Pitfalls

- A longer context does not by itself guarantee that an agent retrieves the right evidence.
- A successful final answer does not prove that intermediate memory writes were useful.

## Research Opportunities

- Compare retrieval policies under the same tasks, model and token budget.
- Record which retrieved item changes a decision, then test a no-memory control.
